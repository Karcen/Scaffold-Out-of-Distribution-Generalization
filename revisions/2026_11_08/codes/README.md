# Scientific code

Run commands from the dated revision root. `prepare_public_inputs.py` only prepares public input access and hash records. The common pipeline is `repro/run_submission_revision.py`; reviewer controls and analyses are in `review_2026_10_14/`. `plot_available_figures.py` redraws seven figures from the included aggregate tables without fitting models.

Source snapshots under `../results/` retain recorded fitting/analysis variants. Configuration and historical-source identities are separate from the current portable entrypoints. Molecular inputs and complete fitted-result records are prerequisites for numerical reruns and are not supplied by this code release. Native Word conversion and private manuscript-management tools are omitted.
