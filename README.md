# Structural-frontier OOD audit for ADMET models

This repository reproduces a six-endpoint evaluation that contrasts an ordinary
scaffold allocation with a label-free structural frontier. The central
comparison fixes the 70/10/20 ratio and deterministic acyclic grouping, then
changes only the seeded size-aware scaffold allocation versus ranking by sparse,
physicochemically remote support.

The recorded corpus contains 468 complete runs, 5,616 metric rows and 120 split
manifests. The main negative result is itself part of the contribution: the
strict matched frontier increases equally weighted primary error by 130.277%,
whereas MV-FREX changes normalized frontier error by only +0.1595% relative to
ERM, with a descriptive interval crossing zero.

---

## Important: run everything from the project root

**All scripts use pure relative paths** (for example `Path("results")`,
`Path("data/external")`). They do **not** resolve the project root from the
script's own location. This means every command below must be executed with the
repository root as the current working directory:

```bash
cd /path/to/data_and_codes   # the folder containing this README
```

If you run a script from inside `scripts/` or any other sub-directory, it will
fail with `FileNotFoundError` because the relative paths will not resolve
correctly. The `sys.path` bootstrapping inside each script inserts `"."` (the
current directory) so that `import src` works — again, this only succeeds when
the current directory is the project root.

## Script reference

Every script lives in `scripts/` and is invoked as
`python scripts/<name>.py` from the project root. Below is a one-line summary of
what each one does; the module docstring inside each file has full detail.

| Script | Purpose |
|---|---|
| `download_external_data.py` | Download the six TDC tables from Harvard Dataverse into `data/external/`. |
| `diagnose.py` | Phase-1 data and provenance audit: molecule validity, scaffold counts, label semantics, duplicate conflicts, SHA-256 hashes. Writes `results/diagnostics.json`, `results/provenance.json`, `results/endpoint_summary.csv`, `results/external_task_summary.csv`. |
| `run_experiments.py` | Resumable multi-seed scaffold/frontier experiment runner. Trains ERM, V-REx, GroupDRO, CVaR, MV-FREX (plus ablations and linear controls). Writes per-run outputs under `results/runs/` and aggregates `results/metrics.csv`. |
| `analyze_results.py` | Aggregate raw runs without filtering. Computes primary summaries, paired split effects, method effects, robustness metrics, view/frontier correlations, calibration, MW-sensitivity, certificates, and bootstrap statistical summaries. |
| `run_cmnpd_audit.py` | Audit experimental models on the CMNPD natural-product teacher domain. Quantifies structural novelty and teacher/student divergence. Requires the licensed CMNPD CSV. |
| `analyze_reviewer_priority1.py` | Post-hoc reviewer diagnostics: prevalence/outcome standardisation, leave-one-endpoint-out sensitivity, BBB rank-reversal decomposition. Writes to `results/reviewer_priority1/`. |
| `analyze_external_splits.py` | Compare frontier against Lo-Hi / DataSAIL hard splits over the matched control. Writes `results/external_split_effects.csv`. |
| `export_harmonized_smiles.py` | Export each task's harmonised SMILES (pipeline order) for external splitters. Writes `results/external_splits/<TASK>__data.csv`. |
| `make_external_splits.py` | Generate Lo-Hi and DataSAIL 70/10/20 partitions (requires Python 3.11 + `lohi_splitter` + `datasail-lite`). |
| `run_external_splits.py` | Run ERM under externally generated Lo-Hi / DataSAIL splits, reusing the primary pipeline. |
| `run_gnn_control.py` | Run the message-passing (GINE 3×128) capacity control on matched-scaffold and frontier splits. Requires PyG. |
| `make_tables.py` | Generate deterministic booktabs LaTeX tables from recorded result files into `tables/`. |
| `make_figures.py` | Generate publication figures (SVG/PDF/PNG/TIFF) and source-data traces. Writes `figures/figure_manifest.json`. |
| `build_artifact.py` | Build a deterministic anonymous supplementary archive (`supplementary_artifact.zip`) with a SHA-256 manifest. |

## Exact environment

The recorded run used Python 3.13.9 on a 10-core Apple M4 CPU with 24 GB memory;
CUDA and MPS were disabled. Core package versions are pinned in
`requirements.txt` (version floors) and `requirements-lock.txt` (exact pins,
if present).

```bash
python3.13 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

The original aggregate training time after featurisation was 217.300 seconds
(mean 0.464, maximum 2.062 seconds per run). Feature construction and platform
differences add overhead.

Optional review-control dependencies (only for `run_gnn_control.py` and
`make_external_splits.py`):

- `run_gnn_control.py` requires PyTorch Geometric. It looks for an optional
  `.deps/` directory and appends it to `sys.path` so the pinned core NumPy is
  not shadowed.
- `make_external_splits.py` requires `lohi_splitter` (pip) and `datasail-lite`
  (conda) in a Python 3.11 environment.

## Reproduce the recorded run corpus

> **Reminder:** run every command from the repository root (the directory
> containing this `README.md`).

The first command produces the conventional 80/10/10 scaffold context, frontier
runs, three fixed-penalty controls, MV-FREX, ablations and frontier linear
controls. The next two commands add the ratio-matched and strict
ratio/group-matched ERM controls. Existing complete run IDs are skipped; add
`--force` only when an intentional full retraining is desired.

```bash
python scripts/diagnose.py
pytest -q
python scripts/run_experiments.py --include-ablations --include-linear-control
python scripts/run_experiments.py \
  --splits scaffold_matched \
  --methods ERM \
  --include-linear-control
python scripts/run_experiments.py \
  --splits scaffold_clustered_matched \
  --methods ERM \
  --include-linear-control
python scripts/analyze_results.py
python scripts/run_cmnpd_audit.py
python scripts/make_tables.py
MPLCONFIGDIR=.mplconfig python scripts/make_figures.py
```

`run_cmnpd_audit.py` can be omitted when the licensed CMNPD source is
unavailable; the primary TDC experiment and strict split claim do not depend on
it. When it is omitted, `make_figures.py` will still produce all figures except
the CMNPD embedding/teacher-agreement panels (those require CMNPD-derived
summaries).

## Interpretation boundaries

- Classification error is 1 − AUROC or 1 − AUPRC; regression error is MAE. The
  paper also reports a chance-adjusted CYP2D6 sensitivity and taskwise effects.
- Bootstrap intervals resample six tasks and paired algorithmic seeds. They are
  not population confidence intervals for all ADMET endpoints or independently
  sampled test scaffolds.
- V-REx-style, smooth worst-group and sample-tail CVaR-style denote the fixed
  implementations in `src/objectives.py`, not canonical or tuned reproductions of
  every published algorithm.
- CMNPD annotations are legacy model outputs. All CMNPD AUROC, MAE and
  correlation values quantify teacher agreement only.
- Proposition 1 applies to a fixed predictor, view maps and bins evaluated on an
  independent non-empty sample under invariant within-bin conditionals. It is
  not a post-selection certificate for the executable minibatch regulariser.
